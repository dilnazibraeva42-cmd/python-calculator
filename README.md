# Python Calculator

Консольный калькулятор на Python с интерактивным меню.

## Описание проекта

Программа выполняет арифметические операции в консоли: пользователь выбирает действие в меню, вводит два числа и получает результат. Ввод проверяется: если вместо числа введён текст, программа просит повторить ввод. Проект создан в учебных целях для практики работы с ветками Git и GitHub.

## Возможности

| Операция | Описание | Функция |
|----------|----------|---------|
| Сложение | сумма двух чисел | `add` |
| Вычитание | разность двух чисел | `subtract` |
| Умножение | произведение двух чисел | `multiply` |
| Деление | частное, защита от деления на ноль | `divide` |
| Степень | возведение числа в степень | `power` |
| Процент | процент от числа | `percent` |

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/dilnazibraeva42-cmd/python-calculator.git
   cd python-calculator
   ```

2. Создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv venv
   source venv/Scripts/activate
   ```

   В командной строке Windows: `venv\Scripts\activate`.

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
python -m src.main
```

## Использование

Пример работы: возведение 2 в степень 10.

```text
=== Python Calculator ===
1. Сложение
2. Вычитание

4. Деление

6. Процент от числа

Первое число: 2
Второе число: 10
Результат: 1024.0
```
